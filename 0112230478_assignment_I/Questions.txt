Output:
0 1 2 3 2 1 0 1 2 3 2 1 0.....

2) Design a program using three threads to print numbers 1, 2, 3 in strict sequence repeatedly. 
Output:
1 2 3 1 2 3 1 2 3 1 2 3.....

3) Implement two threads: one thread continuously generates a random number and stores it in a shared variable. The second thread reads the generated number and adds it to a shared running sum.

Generated: 5

Generated: 3
Sum: 8

Sum: 15
